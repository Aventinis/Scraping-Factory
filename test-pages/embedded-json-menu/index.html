Scraping Factory — Test-Seite (Issue #136, embedded JSON source) Diese Seite lädt keine einzelne Karte per fetch()/XHR nach — die komplette Speisekarte steckt bereits fertig im <script id="__NEXT_DATA__" type="application/json">-Tag im Quelltext (wie bei einer echten Next.js-Seite) und wird per kleinem Inline-Skript direkt aus diesem Blob ins DOM geschrieben. Netzwerk-Aufzeichnung findet hier absichtlich nichts — in der Extension stattdessen "In eingebetteten JSON-Daten der Seite suchen" verwenden und z. B. auf einen Gerichtnamen oder Preis klicken.
