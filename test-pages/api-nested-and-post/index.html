Katalog-Demo
Testfixture für API-Modus (verschachtelte Antworten, POST, GraphQL)
Diese Seite ruft beim Laden drei Endpunkte desselben lokalen Servers auf (same-origin, kein CORS nötig): GET /api/catalog, POST /api/search und POST /graphql. Alle drei liefern denselben dreistufig verschachtelten Katalog (Kategorie → Unterkategorie → Produkt, plus Tags als Array). Jeder Button unten löst die jeweilige Anfrage erneut aus — nützlich, um eine Aufnahme im Erweiterungs-Popup gezielt neu zu triggern.
